# Иструкция запуска и установки:

---
- 1. Скачайте к себе на ПК проект весь либо файлы main.py и requirements.txt
- 2. Поместите их в одну папку и выполните одну из комманд в зависимости от вашего питона: `python venv venv`, `py -m venv venv`, `py venv venv`, `python -m venv venv`.
- 3. Выполните `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser`
- 4. Выполните `.\.venv\Scripts\Activate.ps1`
- 5. Выполните `pip install -r -requirements.txt`
- 6. Запустите `uvicorn main:my_app --reload`
- 7 Откройте `127.0.0.1:8000`
